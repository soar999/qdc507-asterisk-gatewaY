# Sanitized public source snapshot

This is a source-review archive, not a deployable copy. Private site-specific
ADB device identifiers, domain names, and selected public endpoints were
replaced with nonfunctional examples ONLY in the temporary Git worktree.
The original production NAS files and source ZIP are unchanged.

The `source-manifest.json` hashes refer to this sanitized public copy; they
are intentionally not hashes of the original private source files.
Use original production configuration locally and never apply this public
snapshot to a live gateway without reconstructing/verifying site settings.

Automated secret scans do not replace careful manual review. Do not publish
production pjsip.conf, extensions.conf, registration secrets, SMS bodies,
logs, device subscriber identifiers or captured packet/audio data.
